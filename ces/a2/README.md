# A2 - Replacing for Loops with map/filter/reduce (TypeScript)

This project contains **6 examples** where classic `for` loops are replaced with:
- `map`
- `filter`
- `reduce`

## Included examples
1. `map` for squares of numbers
2. `filter` for even numbers
3. `reduce` for the sum of numbers
4. `map` for extracting student names
5. `filter` for selecting students who passed
6. `reduce` for average grade

## Run
```bash
cd a2
npm install
npm run build
npm start
```
